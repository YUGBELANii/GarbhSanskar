# Sampurnatavan Garbhsanskar

A calm, responsive informational website demo for a Garbh Sanskar practitioner. The visual direction uses warm ivory, muted gold and natural sage tones, inspired by the supplied brand artwork.

## Run locally
Open `index.html` in a browser. No build step or dependencies required.

## Pages
Home, About, Garbh Sanskar, Programs, Resources, Testimonials and Contact.

## Mobile
Responsive layouts, touch-friendly buttons, horizontally scrollable navigation on small screens, and readable form controls.

## Before publishing
Replace sample practitioner identity, qualifications, contact details, program information and testimonials with verified details. Configure the enquiry email in `script.js`. Educational content is not medical advice; pregnancy care should be guided by qualified healthcare professionals.

## Database
No database is needed for this static demo. Consider one later only if the practitioner needs editable articles/programs, stored enquiries, bookings, payments, or member accounts.
